## Schemas

**ER taps:** `mode` (1–6), `mode_name`, `room_size`, `channel` (L/R), `tap` (1-based), `time_ms` (from the panel's 0 ms origin, i.e. **includes** the ~20 ms first-tap offset), `gain_db` (0 dB = top of the chart), then `confidence` or `pixel_width`.
